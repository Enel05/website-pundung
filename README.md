# Jelajah Indonesia

Website wisata Indonesia mobile-first dengan hero carousel video, peta destinasi, spotlight budaya, dan panel asisten perjalanan Maia.

## Menjalankan

```bash
npm install
npm run dev
```

Buka URL lokal yang ditampilkan Vite. Video pada carousel memakai URL demo remote dan dapat diganti di array `destinations` pada `src/main.jsx`.
